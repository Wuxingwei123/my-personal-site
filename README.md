# 个人作品集 · React + Vite

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

页面包括全屏视频首页、个人介绍、精选项目、创作优势、联系收尾页。版心最大 1700px，适配 PC 与手机。项目卡片可点击查看简介，背景视频可暂停，支持锚点导航。

已按提供的个人项目经历更新文案、能力和成果数据，展示两个账号项目与一项方法沉淀。姓名、头像、联系方式、账号截图和作品链接待补充，项目封面为氛围示意图。后续在 `src/main.jsx` 替换真实资料。图片使用 Unsplash 远程资源，背景视频使用 Pexels 远程资源，加载需要联网；视频未加载时显示静态封面。正式上线建议替换为自有并确认授权的本地素材。


公众号项目已加入账号、文章前台与后台详细数据截图；关注人数采用截图值 11,944，代表图文阅读采用后台值 1,176,235。前后台数据差异已在页面注明。素材位于 public/assets/wechat。
